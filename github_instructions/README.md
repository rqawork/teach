# Cloning the Repository

To download a copy of this repository to your computer, be sure that you have first installed git and then open a terminal on Linux or Mac (or Windows Powershell on Windows) and run:

```bash
git clone https://github.com/rqawork/teach.git
```

This command works on **Windows**, **macOS**, and **Linux**.

After cloning, enter the repository folder:

```bash
cd teach
```

You now have a local copy of the repository and can access all files on your computer. You can repeat the clone command above to get the latest version of the repository each time it has been updated.
