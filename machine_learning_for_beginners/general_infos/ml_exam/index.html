Final ML Exam

General Instructions

The exam consists of a presentation of an ML investigation described by the steps below, as well as the submission of the corresponding Python code.

Submit a Jupyter notebook file named:

Lastname_Firstname_ImmatriculationNumber.ipynb

Send the notebook to albuquerque@uni-bayreuth.de by the deadline: To be announced

On the day of the presentation (place / time to be announced), deliver a talk of 12 min ±2 clearly addressing each step below, followed by approximately 5 min of general questions.

Exam Steps

01

Choose Your Dataset

Select any suitable regression dataset. Public sources such as Kaggle.com are allowed.

Make sure the dataset has:

  • Enough samples
  • Clear input features
  • At least one continuous target variable
02

Train–Test Split (Very Important!)

Split your dataset into 80 % training and 20 % test.

Do not touch the test set until the very end. It must not be used for model selection, hyperparameter tuning, or cross-validation. The test set is reserved exclusively for the final evaluation.
03

Train and Screen Models

Test at least the following regression models:

  • Random Forest (RF)
  • Support Vector Regression (SVR)
  • k-Nearest Neighbors (KNN)
  • LASSO
  • Gaussian Process (GP)

Model Screening

  • Use 5-fold Cross-Validation (CV)
  • Perform CV only on the training set
  • Optimize hyperparameters if needed
04

Evaluate Model Performance

During model screening, report:

  • MAE – Mean Absolute Error
  • MSE – Mean Squared Error
  • R² – Coefficient of Determination

Compare all models and select the best one.

05

Final Test Evaluation

After selecting the best model:

  • Retrain the model using the full training set
  • Evaluate it once on the test set

Show a parity plot (Predicted vs. True values) and the performance metrics. This is your final result.

06

Training Performance

Evaluate your best model on the training data and show:

  • Parity plot
  • Performance metrics

This helps analyze overfitting.

07

Overfitting Analysis

Compare training error vs. test error and discuss:

  • Is the model overfitting?
  • Is it underfitting?
  • Why?
08

Model Variance (Stability)

To evaluate model stability:

  • Use the best screened model
  • Apply repeated 5-fold CV on the training set only
  • Use 10 different random seeds

Report the average MAE and its standard deviation. Discuss what these values indicate about model stability and robustness.

09

Ensemble Model

Combine the two best individual models into a simple ensemble (e.g., by averaging predictions).

Compare ensemble performance against the best individual model and discuss the advantages and disadvantages.

Guidance

Good Practice

  • Keep your work reproducible
  • Fix and report random seeds
  • Explain your decisions
  • Use clear plots and labels
  • Practice your presentation timing

Common Mistakes to Avoid

  • Using the test set during model tuning
  • Missing preprocessing steps
  • Not explaining methods clearly
  • Poorly labeled figures
  • Exceeding the presentation time limit
